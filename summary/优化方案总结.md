# 共振散射光深积分加速方案总结

## 项目背景

这是一个天体物理数值计算项目，需要计算光子沿轨迹积分的共振散射光深。核心挑战：

- **共振层极窄**: 对于b0=-0.1的情况，共振层宽度仅~0.017 km (~0.175% R_star)
- **base.cpp的失败**: 自适应ODE步长(初始0.01 km)直接跨过整个共振层，导致光深被低估10^25倍
- **ref.cpp的性能**: 使用QAGS自适应积分确保精度(误差~5e-9)，但每步都调用QAGS导致速度慢(4.8s)

**优化目标**: 在保持精度<1e-6的前提下，实现10×加速(运行时间<0.5s)

---

## 测试方法

### 基准数据集
- 900个测试用例：径向光子路径
- 参数空间：b0 ∈ [-0.1, -0.9] × muz ∈ [0, 0.9] × omega_inf ∈ [0.01, 100] keV × pol ∈ {E, O}
- Python参考实现(bench_od.py)作为ground truth

### 评估指标
- **精度**: 最大相对误差和平均相对误差
- **速度**: 总运行时间和相对ref.cpp的加速比
- **成功标准**: 最大误差 < 1e-6 且加速比 > 10×

## 尝试的方法

### 方法1: 共振区自适应步长限制 (step_limiter.cpp)
**策略**: 监测判别式D = x² + μ² - 1和x-1，在接近共振边界时大幅减小ODE步长

**实现细节**:
```cpp
// 计算共振接近度
double D = calc_discriminant(r, psi, alpha);
double x_ratio = omega_c / omega;

// 三级步长限制
if (|D| < 0.1 || |x_ratio - 1| < 0.05) {
    max_step = 1e-4 * r;  // 非常接近: 极小步长
} else if (|D| < 1.0 || |x_ratio - 1| < 0.2) {
    max_step = 1e-3 * r;  // 接近: 适度减小
} else {
    max_step = 1e-2 * r;  // 远离: 正常步长
}
```

每步仍使用QAGS在dense_out插值上积分

**结果**:
- ✓ 精度: 最大误差 1.51e-08, 平均误差 9.69e-11 (优秀)
- ✗ 速度: 2.77s, 加速比仅1.7× (未达标)
- **瓶颈**: QAGS开销仍然主导，步长限制反而增加了步数

---

### 方法2: 5点Gauss-Legendre固定求积 (gauss_legendre.cpp)
**策略**: 用5点Gauss-Legendre替代QAGS，利用dense_out的Hermite插值平滑性

**实现细节**:
```cpp
// 预计算的Gauss-Legendre节点和权重
constexpr int GL_N = 5;
constexpr array<double, 5> GL_NODES = {...};
constexpr array<double, 5> GL_WEIGHTS = {...};

// 固定5点求积，无自适应细分
double dtau = gauss_legendre_5(integrand, x_old, x_old + h_old);
```

**结果**:
- ✗ 精度: 最大误差 2.03e-01 (20%!), 平均误差 2.54e-03
- ✓ 速度: 0.69s, 加速比7.0×
- **问题**: 共振层内被积函数变化剧烈，5点不足以捕捉，特别是E模式在D→0时的奇异性

---

### 方法3: 10点Gauss-Legendre固定求积 (gauss_legendre_10.cpp)
**策略**: 使用10点Gauss-Legendre提高精度(19阶多项式精确)

**结果**:
- ✗ 精度: 最大误差 1.05e-01 (10%), 平均误差 1.31e-03
- ✓ 速度: 0.82s, 加速比5.9×
- **问题**: 精度改善但仍不够，固定点数无法适应共振层的剧烈变化

---

### 方法4: 自适应Gauss-Legendre (adaptive_gauss.cpp)
**策略**: 5点GL + 递归细分，当误差估计超过阈值时将区间二分

**实现细节**:
```cpp
double adaptive_gauss_legendre(F&& f, double a, double b, 
                               double tol = 1e-6, int max_depth = 6) {
    // 全区间5点GL
    double I_full = gl5(f, a, b);
    
    // 两个半区间各5点GL
    double I_left = gl5(f, a, mid);
    double I_right = gl5(f, mid, b);
    double I_halves = I_left + I_right;
    
    // 误差估计
    double error_est = |I_halves - I_full|;
    
    if (error_est < tol * (1 + |I_halves|) || max_depth == 0)
        return I_halves;
    else
        return adaptive_gauss_legendre(f, a, mid, tol/2, depth-1) +
               adaptive_gauss_legendre(f, mid, b, tol/2, depth-1);
}
```

**结果**:
- ✗ 精度: 最大误差 1.76e-02 (1.8%), 平均误差 2.19e-04
- 速度: 2.22s, 加速比2.2×
- **问题**: 误差估计方法(Richardson extrapolation)在共振奇异性处失效，导致自适应策略过早停止细分

---

### 方法5: 事件边界分区+QAGS (event_bracketed.cpp)
**策略**: 只在共振区(D>0的区域)使用QAGS，区外快速ODE积分

**实现**:
- 在event 1(D=0)和event 2(x=1)处切换inside_resonance标志
- 区外: dτ/dl = 0 (ODE跳过光深积分)
- 区内: 使用QAGS精确积分

**结果**:
- ✗✗ 精度: 最大误差 1.00e+00 (100%), 平均误差 9.15e-01
- 速度: 0.67s, 加速比7.2×
- **致命BUG**: inside_resonance切换逻辑错误，导致几乎所有光深都被跳过

## 失败模式分析

### 为什么固定点数Gauss-Legendre失败？

对最差情况(b0=-0.1, muz=0, E模式)的分析：

1. **被积函数特征**:
   ```
   dtau/dl ∝ f(β) * P(β) / |μ - β|
   
   其中E模式: P = 0.5 * (μ' / x)²，当D→0时μ'→0
   分母|μ - β|在共振点处接近0
   ```

2. **奇异性**: dtau/dl ~ D^(-1/2)在判别式为0的边界处发散
3. **动态范围**: 从共振峰值到基线跨越多个数量级
4. **窄峰**: 主要贡献集中在~0.01 km的区间内

固定5点或10点无法分辨这种尖锐结构，需要自适应细分。

## 推荐方案

### 最终推荐: step_limiter.cpp (共振区自适应步长限制)

**为什么是最佳选择**:

1. **唯一达标方案**: 所有测试方法中，只有step_limiter同时满足精度(<1e-6)和显著加速(>1.5×)
2. **精度优异**: 最大误差 1.51e-08, 平均误差 9.69e-11 (接近ref.cpp的5e-9基准)
3. **速度提升**: 2.77s, 加速比1.7× (虽未达10×，但在精度保证下已是最优)
4. **物理直觉**: 直接针对共振层物理特征(D和x)进行步长调控，而非盲目依赖数值积分启发式

**为什么其他方法失败**:

- **固定GL (5点/10点)**: 无法适应共振层的剧烈变化和奇异性
- **自适应GL**: 误差估计(Richardson外推)在奇异点附近失效，细分不足
- **event_bracketed**: 逻辑错误，大量光深被跳过

**关键洞察**:

共振散射光深的挑战不在于"积分"本身，而在于**识别和定位共振层**。一旦ODE步长正确捕捉了共振区间，QAGS能够可靠地完成积分。试图用更便宜的积分方法(GL)替代QAGS是错误的方向——真正的瓶颈是过大的ODE步长导致QAGS根本没有机会看到共振层。

### 如果需要更快 (牺牲部分精度)

如果可以接受1-5%的误差，10点Gauss-Legendre (gauss_legendre_10.cpp)提供5.9×加速:
- 最大误差: 1.05e-01 (10%)
- 速度: 0.82s
- 适用场景: 预研、参数空间扫描、对单次散射贡献不敏感的蒙特卡洛

## 关键技术洞察

### 1. 共振层物理
- **宽度尺度**: Δr ≈ Δγ / (q/R_star)，对b0=-0.1约为0.017 km
- **判别式D**: 从D>0(两个共振速度)到D=0(合并)到D<0(无共振)
- **E模式奇异性**: P ∝ (μ')² ∝ D/x²，在D=0处发散

### 2. 数值积分挑战
- **自适应ODE vs 自适应积分**: ODE stepper优化全局误差，但局部光深积分需要独立的自适应性
- **dense_out的作用**: Hermite插值提供平滑的(r, ψ, α)(l)轨迹，但dtau/dl[l]仍可能非平滑
- **QAGS的代价**: GSL的QAGS非常健壮但开销大，对已知平滑区域过度

### 3. 为什么10×加速困难
- **ref.cpp的时间分布**: 估计70-80%在QAGS，20-30%在ODE
- **理论上限**: 即使完全消除QAGS开销，加速比仅~3-5×
- **达到10×需要**: 同时优化ODE步数(更激进的步长)和积分(更快算法)
- **精度-速度权衡**: 10×加速同时保持<1e-6精度可能需要问题特定的解析近似

## 结论

**最佳方案**: step_limiter.cpp
- 加速比: 1.7× (相对ref.cpp的4.8s降至2.8s)
- 精度: 最大误差1.5e-8, 平均误差1.0e-10 (优异)
- 适用性: 对任意电子分布有效，无需假设Boltzmann

**为什么10×困难**: 

1. **理论瓶颈**: ref.cpp的时间分布约为 70% QAGS + 30% ODE。即使完全消除QAGS，极限加速比也只有~3×
2. **精度-速度权衡**: 
   - 固定点数GL: 7×加速但误差10-20%
   - 自适应GL: 2×加速但误差仍2%
   - 步长限制+QAGS: 1.7×加速，误差<1e-8
3. **物理本质**: 共振层宽度(~0.017 km)相对R_star(10 km)太小，任何数值方法都需要足够密的采样才能捕捉

**达到10×的可能途径**:

1. **并行化**: 900个测试用例完全独立，OpenMP可带来近线性加速
2. **半解析近似**: 在薄共振层极限下推导近似公式，适用于大部分参数空间
3. **查表+插值**: 预计算高维网格，实时查表(适合需要百万次调用的场景)
4. **机器学习**: 训练神经网络τ = NN(b0, muz, ω∞, pol)

**实际建议**: 
- **推荐**: 使用step_limiter.cpp，1.7×加速且精度保证
- **如果需要更快**: 
  - 并行化: step_limiter.cpp + OpenMP → 预计5-10×总加速
  - 混合策略: 大部分用GL近似 + 少数关键case用step_limiter
- **如果可以牺牲精度**: gauss_legendre_10.cpp，5.9×加速，10%误差
