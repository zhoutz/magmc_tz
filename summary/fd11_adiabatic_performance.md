# 更换偏振启动事件前后的运行效率

**默认配置下有明显的耗时增加：完整程序的中位耗时从 10.73 秒变为 12.91 秒，增加 20.3%。**
结果依赖参数；本次低能量样本反而更快，不能说所有配置都变慢。

## 对照版本和方法

- 改动前：提交 `06a7488`，仍在 `advance_polarization()` 内按旧的式 (34) 判据定位启动点。
- 改动后：提交 `1055a2b`，按 `|d chi_B/dl| - 1e-3*kappa` 的测地线事件启动。
- 两份源码直接从 Git 提取，分别编译，不改变工作区的 `src/dev/fd11.cpp`。
- 两个版本间的公共 C++ 头文件未改变；使用相同工作区的磁场表和依赖。
- Darwin arm64，Homebrew GCC 16.2.0，编译参数 `-std=c++23 -O3`，相同 GSL 链接参数。
- 每组使用相同光子数、能量、初态和随机种子，前后版本各跑三次，交替执行顺序，全部串行。
- 正式计时前，各版本先运行 100 光子预热，排除新编译二进制首次启动的额外开销。
- 下表采用从进程启动到结束的完整墙钟时间中位数，包含程序初始化、模拟和输出。
  同时保存了程序内部光子循环计时；默认组分别为 10.704 秒、12.879 秒，结论一致。

这是用户要求的实际改动前后对照，包含新判据造成的积分区间、ODE 步数和散射历史变化。
`--couple` 在两个版本中均使用默认值 `1e-3`，但对应的物理判据已经不同。
本测试没有把事件框架、方向导数计算和物理轨道变化的耗时分别剥离。

## 结果

时间单位为秒；正百分比表示改后更慢，负百分比表示改后更快。

|光子数|能量 keV|初态|种子|改前|改后|耗时变化|
|---:|---:|:---:|---:|---:|---:|---:|
|10000|1|E|7774|10.730|12.905|+20.3%|
|1000|0.1|E|4193|3.944|3.046|−22.7%|
|1000|1|E|4193|2.265|2.354|+3.9%|
|1000|10|E|4193|0.513|0.622|+21.3%|
|1000|0.1|O|4193|3.014|2.425|−19.6%|
|1000|1|O|4193|0.657|0.713|+8.7%|
|1000|10|O|4193|0.446|0.422|−5.3%|
|1000|1|E|8171|0.957|1.185|+23.8%|
|1000|1|E，关闭偏振|4193|0.404|0.388|−3.9%|

默认 10000 光子的三次原始墙钟时间为：

- 改前：10.729503、10.583105、11.384788 秒。
- 改后：12.952285、12.905233、12.752365 秒。

改后三次均慢于改前三次，约 20% 的差别大于这组重复计时的波动，可认为是有实际意义的性能下降。
三次重复不构成对所有机器、能量、随机种子或发射分布的统计保证；约几个百分点的小差别应谨慎解释。

计算使用

\[
\Delta T=\left(\frac{\operatorname{median}(T_{\rm after})}
{\operatorname{median}(T_{\rm before})}-1\right)\times100\%.
\]

20.3% 是**耗时增加**；对应的每秒光子吞吐率下降约 16.9%，两者不能混写。

## 工作量变化

默认样本的计数如下：

|计数|改前|改后|
|---|---:|---:|
|偏振积分启动次数|9942|4950|
|偏振接受步数|636704|436245|
|偏振拒绝步数|4483|10909|
|偏振积分启动后发生的散射次数|48|212|
|总散射次数|10062|10051|
|逃逸光子数|9893|9892|

新版本减少了启动次数和接受步数，但拒绝步数与启动后发生的散射次数增加。
此外还需要求磁场方向导数。单看接受步数不能推断整体运行更快；上述计数没有给出各函数的耗时占比，
所以本次不把总耗时增加归因于某一个函数。

当前驱动仍是随机表面位置、初始径向发射，散射后方向随机。这里测的是当前程序实际使用的发射模型。
新旧条件并非同一物理初始化近似，输出不同不能直接解释为数值误差。

所有 54 次正式运行均正常结束，输出有限值、逃逸/吸收计数和 Stokes 范数检查通过。
同一版本、同一配置的三次输出文件哈希一致。

## 复现和文件

```sh
python3 src/dev/py/benchmark_adiabatic_event.py
```

脚本默认固定对比以上两个提交，也支持 `--before`、`--after`、`--repeats` 和 `--timeout`。
临时 C++ 源码只在 `src/dev/` 中生成，编译完自动删除；二进制为
`build/fd11_event_before` 和 `build/fd11_event_after`。

原始记录位于 `output/fd11_adiabatic_benchmark/`：

- `metadata.json`：完整提交号、源码 SHA256、编译参数和平台。
- `runs.json`：每次正式运行的命令、墙钟时间、内部时间及计数。
- `analysis.json`：各组中位数、原始时间数组和相对变化。
- 各组 `.txt`、`.log`：逃逸光子数据和标准错误日志。

本次只进行性能对照，没有修改生产代码。
