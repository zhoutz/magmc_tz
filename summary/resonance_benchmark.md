# 共振光学深度积分：方法比较与非径向验证

## 结论

建议采用 `src/bench/velocity_panels.cpp` 的速度事件分段方案。它先在完整 Schwarzschild 轨道上定位电子分布的速度边界/窄峰标记及 `D=0`，再分段积分光学深度。误差为零的 RK 步不再被当作该区间无共振的证据。

实现并实测了三种方案：`ft07.cpp`、`geometric.cpp`、`velocity_panels.cpp`。原始 `base.cpp`、`ref.cpp` 和其他目录的既有代码均未修改；新增代码及复现实验脚本全部位于 `src/bench/`。结果在 `output/`，原始 `table/bench_od.txt` 保持原样。

## 方法与适用范围

| 程序 | 实现 | 主要限制 |
|---|---|---|
| `geometric.cpp` | 保留四维轨道/τ 耦合 DOPR5；每步调用 `do_step(0.001*r)` | 参数不随电子分布的窄峰宽度变化，仍可能漏层 |
| `ft07.cpp` | FT07 速度空间限步 + 本次的共振边界分段与端点积分 | 是 FT07 步长规则在本项目物理模型下的组合实现，不能把其精度全部归因于限步规则 |
| `velocity_panels.cpp` | 三维轨道 DOPR5；默认 `h≤0.2r`；定位速度事件；每个区间作开节点 8/16 点 Gauss 积分 | 需要分布提供不连续点和窄峰标记；事件探测仍需做分辨率收敛检查 |
| `ref_general.cpp` | 沿用 `ref.cpp` 的小轨道步 + 空间 QAGS；默认 `h≤0.01r` | 改正径向专用边界与终止假设；用于非径向和通用分布对照 |

### FT07 的具体对应

依据 [FT07 原文](../article/FT07.pdf) §3.3–3.4（期刊页 621–623，式 31、38、39）：远离有效速度范围用 `r/10`；接近范围边缘时用半宽的 `1/100` 分辨边缘；范围内采用 `|Δβ|=(1−β²)|β|/100`，即相对动量步长 1%；在合并点附近限制 `|Δ(μ−β)|/|μ−β|`。同时检查两支速度。β=0 的特殊分支用分布半宽给出小的非零速度步。

令 `x=ωc/ω`，实现中的路径导数为

```text
dβ/dl = [(1−βμ) dln(x)/dl + β dμ/dl] (1−β²)/(β−μ).
```

`dln(x)/dl` 含引力红移，`dμ/dl` 含光线弯曲和磁场方向变化，均沿完整轨道计算。论文原本忽略引力，因此这是对本项目方程的适配。物理截面和电流归一化采用用户 note 中的 `1/|平均β|`，没有照搬 note 已指出不一致的个体速度归一化。

Boltzmann 适配器以 0.001、0.5、0.999 分位点描述 FT07 的有效范围；**这些分位点只控制步长，没有裁掉 0.2% 的电子分布**。多峰分布可以提供多个范围。相对间隙限步会无限逼近简单合并点，所以 `D≤10⁻⁸` 时交给事件分段积分跨越端点。报告的 FT07 结果包含这项补充，不是论文全套 Monte Carlo 算法的逐字复刻。

### 显式分段为何能防止漏层

对每个由分布提供的速度标记 βᵢ，求沿路径的零点：

```text
Fᵢ(l) = ln x(l) − ln(1−βᵢ μ(l)) + ½ ln(1−βᵢ²).
D(l) = x(l)² + μ(l)² − 1.
```

在一个轨道步的 dense output 上采样并定位 Fᵢ、D 的符号变化；采样显示有内极值时，再搜索极值以捕获端点同号的共振小区间。排序所有边界后分别积分。因此即使整个窄层都位于一个轨道步内部，也可由速度事件找到。全过程以路径长度为自变量，没有单调半径或恒定 μ 假设。

E 模的简单合并点具有 `D⁻¹/²` 的可积奇性。区间使用 `l=a+(b−a)sin²(πz/2)` 消除端点奇性；在极小邻域用沿轨道的局部二阶展开计算 D，避免 `x²+μ²−1` 的浮点相消。两支速度与该 D 保持一致。O 模也通过相同积分接口处理。

### 任意电子分布接口

算法中的 `Distribution` 只需要 PDF 回调、有效支持范围、非零平均速度以及速度标记；FT07 另需每个峰的范围/中心。算法不读取 Boltzmann 温度参数，也不假定单侧或单峰。Boltzmann 分位点的生成仅在 benchmark 适配器中。

任意窄的黑盒峰无法靠有限次采样保证发现；使用者必须把不连续点、支持边界及能分辨窄峰的标记传给接口。此约定适用于一般连续或分段连续的 PDF，未实现 Dirac δ 冷束的独立解析处理。平均速度为零时，当前项目用电流反求密度的归一化本身不适定，需要另行给定密度模型。

## 基准与计时方法

环境：`macOS-15.7.3-arm64-arm-64bit`，GCC `g++-16`，`-std=c++23 -O3`，GSL。单进程串行执行；每套方法先预热整批，再执行 3 次，报告整批耗时的中位数。编译、文件 I/O、磁场加载和分布分位点预计算不计入积分耗时；分布预计算耗时单独存在每个 `_stats.txt` 的 `setup_ms`。收敛/敏感性补充运行通常只计时 1 次，不用于主要效率排名。

径向：原表完整 900 例。非径向：576 例，覆盖南北半球、两种极化、近切向出射、从外部入射、径向转向、撞星，以及固定种子 20260925 的随机轨道；含比原表更冷的 β₀=−0.03。通用分布：144 例，测试宽度 2×10⁻⁴ 的顶帽、两个不连通顶帽的混合，以及跨正负速度的光滑紧支持双峰（窄峰半宽 2×10⁻⁴）。全部初始条件逐行保存于对应输出文件。

非径向文件的 `distribution` 编号为 0=Boltzmann、1=窄顶帽、2=双顶帽、3=光滑紧支持混合。窄顶帽支持区间 (−0.2001,−0.1999)；双顶帽在 (−0.701,−0.699) 和 (−0.1201,−0.1199) 上分别有权重 0.2、0.8；光滑混合在中心 −0.35/0.5、半宽 0.0002/0.03 处分别有权重 0.8/0.2，各分量的归一化形状为 `15(1−z²)²/(16w)`、|z|<1。

非径向参考使用 `ref_general.cpp`，不能直接把 `ref.cpp` 的固定初始纬度 β=0 事件或第一次 `D=0` 即终止的径向假设用于这些光线。广义参考沿轨道更新 μ、磁场与电子分布边界，一直追踪到 r=10000 km 或撞星；经过共振边界不会提前终止。

## 实际集成建议及剩余限制

1. 若只改一行 `max_step`，`0.001r` 是有用的对照，但不是通用修复：窄峰测试仍出现严重漏算。
2. 建议把当前四维耦合积分改成三维轨道积分加速度事件分段 τ 积分；本次已在 benchmark 内实现可运行替代版本。需要散射时设置 `Options::tau_target`，便可返回事件位置。
3. FT07 组合方案可靠但通常做了更多小步。应按实际目标精度和轨道分布选择，而不是只比较同一个名义容差。原始 `ref.cpp` 对径向光线有提前终止优势；其径向耗时不能直接当成非径向通用参考的成本。
4. 本次验证支持当前磁场表与已测轨道/分布。有限探测与极值搜索不构成对任意振荡磁场或未提供窄峰位置的黑盒 PDF 的全局证明；用于新分布、新磁场时应重复标记、步长、探测数和参考积分的收敛检查。简单 D=0 合并点已处理，高阶切触退化点未给出独立解析保证。
5. 总深度及累计深度测试均止于与基准一致的 r=10000 km 或星面。本次没有更改磁场模型，也没有模拟完整的多次散射谱。
