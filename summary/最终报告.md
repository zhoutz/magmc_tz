## 方法说明

### 1. step_limiter.cpp (✓✓ 推荐)
**策略**: 监测共振判别式D和频率比x，在接近共振边界时大幅减小ODE步长

**核心代码**:
```cpp
double D = calc_discriminant(r, psi, alpha);
double x_ratio = omega_c / omega;

if (|D| < 0.1 || |x_ratio - 1| < 0.05) {
    max_step = 1e-4 * r;  // 极小步长
} else if (|D| < 1.0 || |x_ratio - 1| < 0.2) {
    max_step = 1e-3 * r;  // 适度减小
} else {
    max_step = 1e-2 * r;  // 正常步长
}
```

**为什么成功**: 
- 直接针对物理特征(共振边界)进行步长控制
- 确保QAGS有足够细的ODE步来积分
- 适用于任意电子分布和任意光子轨迹

**验证**: 
- **径向路径**: 900个测试用例全部通过 (与bench_od.txt对比)
- **非径向路径**: 216个额外测试用例全部通过 (与ref.cpp对比)
  - 测试参数: α ∈ [0, 0.1, 0.3, 0.5] rad, b0 ∈ [-0.1, -0.3, -0.5], muz ∈ [0, 0.3, 0.6], ω∞ ∈ [0.01, 1, 100] keV
  - 光深范围: [0.050, 12.8], 所有结果有限且物理合理
  - **结论**: 方法适用于任意光子轨迹，不限于径向路径
- 最大误差<2e-8,远优于1e-6目标

### 2. 其他尝试方法

**固定Gauss-Legendre (5点/10点)**: 
- 速度快(7×/6×加速)但精度不足(10-20%误差)
- 问题: 共振层内被积函数变化剧烈,固定点数无法捕捉

**自适应Gauss-Legendre**: 
- 误差估计方法在奇异点处失效
- 实际误差1.8%,不可用

**事件边界分区**: 
- 逻辑错误导致大量光深被跳过
- 理念正确但实现有误

## 关键技术洞察

### 1. 问题本质
共振散射光深的挑战不在"积分"本身,而在**识别和定位共振层**:
- 共振层极窄: 约0.017 km (0.175% R_star)
- base.cpp失败: 步长0.01 km直接跨过整个共振层
- ref.cpp成功但慢: 每步都用QAGS,代价高昂

### 2. 为什么10×困难
**理论瓶颈**: 
- ref.cpp时间分布: ~70% QAGS + ~30% ODE
- 即使完全消除QAGS,极限加速比也只有~3×

**实践发现**: 
- 固定GL: 快但精度不足
- 自适应GL: 误差估计在奇异点失效
- 步长控制+QAGS: 唯一可靠方案

### 3. 达到10×的可能途径
1. **并行化**: OpenMP并行900个独立case → 近线性加速
2. **半解析近似**: 在薄共振层极限下推导近似公式
3. **查表+插值**: 预计算高维网格(适合百万次调用场景)
4. **机器学习**: 训练NN直接预测τ(仅用于参数扫描)
