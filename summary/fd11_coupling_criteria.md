# 可选的 Mode → Integrating 判据与性能比较

> 历史记录：2026-09-29 已按用户要求删除方向转动率判据及选择选项。
> 当前只使用论文判据，以下双判据命令和性能结果对应删除前版本，见 [当前说明](fd11_paper_only.md)。

默认 10000 光子配置下，`fd11` 耗时中位数为 **8.66 秒**，`adiabatic` 为 **12.85 秒**，
后者比前者增加 **48.3%**。低能量组则是 `adiabatic` 较快，具体见后面的完整表格。

## 使用方法

在仓库根目录执行：

```sh
make fd11
build/fd11 --coupling-criterion fd11 --output output/fd11_criterion_fd11.txt
build/fd11 --coupling-criterion adiabatic --output output/fd11_criterion_adiabatic.txt
```

默认选择 `adiabatic`，保留修改前的行为。`--couple` 对所选判据设置无量纲阈值，默认 `1e-3`。
非法名称或缺失参数会报告错误。C++ 接口为 `fd11::Options::coupling_criterion`，
枚举值 `fd11::CouplingCriterion::{FD11, Adiabatic}`；和其他偏振选项一样，应在光子 `init()` 前设置。

## 两种事件函数的推导

令路径变量为局域路程 $l$，半径为 $r>0$，双折射波数差为

\[
\kappa=k_0\Delta n\ge0.
\]

论文 `article/FD11.pdf` 式 (25) 定义积累一弧度相对相位所需的长度

\[
\ell_A=\frac1{k_0\Delta n}=\frac1\kappa.
\]

式 (34) 的过渡面为 $\ell_A/r=10^{-3}$。记可调阈值为 $\epsilon$，
用户要求在 $\ell_A/r>\epsilon$ 一侧开始积分。对于 $\kappa>0$，逐步改写为

\[
\frac1{\kappa r}>\epsilon
\quad\Longleftrightarrow\quad
1>\epsilon\kappa r
\quad\Longleftrightarrow\quad
F_{\rm FD11}=1-\epsilon\kappa r>0.
\]

其中乘以 $\kappa r$ 不改变不等号方向。代码直接计算最后一个表达式；当 $\kappa=0$ 时，
其连续延拓为 $F_{\rm FD11}=1$，避免计算无穷大的 $\ell_A$ 或除以零。
这不是径向光子的特殊分支，对所有几何使用同一公式。

另一个判据来自 `doc/adiabatic.md`。在随横向磁场旋转的本征模基底中，
非对角耦合强度为 $|\chi'_B|$，对角本征值间距为 $\kappa$，故所用比值为

\[
\epsilon_{\rm ad}=\frac{|d\chi_B/dl|}{\kappa}.
\]

对于 $\kappa>0$，启动条件等价于

\[
\frac{|\chi'_B|}{\kappa}>\epsilon
\quad\Longleftrightarrow\quad
|\chi'_B|>\epsilon\kappa
\quad\Longleftrightarrow\quad
F_{\rm ad}=|\chi'_B|-\epsilon\kappa>0.
\]

`FD11` 事件函数无量纲，`Adiabatic` 事件函数单位为 km⁻¹。事件检测只用各自的符号和零点，
所以二者无须使用相同单位。求根时定位等号成立的过渡面，初始已满足（含等号）时在初始点启动。
两个比值在相同阈值下通常不会给出相同启动位置，不能把阈值相同理解为近似精度完全相同。

`adiabatic` 沿用已有方向导数算法。具体而言，取 $\delta=10^{-5}r$，
由测地线方程获得状态切向量 $v=dy/dl$，计算 $y_-=y-\delta v$ 和 $y_+=y+\delta v$。
`pol_coeff` 返回 $c_\pm=\cos(2\chi_\pm)$、$s_\pm=\sin(2\chi_\pm)$。因此

\[
\Delta(2\chi)=\operatorname{atan2}(c_-s_+-s_-c_+,c_-c_++s_-s_+),
\]

\[
\chi'_B\simeq\frac{\Delta(2\chi)}{4\delta}.
\]

分母的一个因子 2 来自双倍角，另一个来自两点间隔 $2\delta$。
沿用原有的舍入噪声处理：双倍角差不超过 16 倍机器精度时视为零。
`fd11` 分支只评估当前点一次 `pol_coeff`，不计算此方向导数。

## 事件与偏振演化

第三个测地线事件仍为 `PolarizationEvent`，回调通过 `coupling_event()` 选择上述函数。
`advance_polarization()` 仍只在 Integrating 阶段积分，不扫描或定位启动点。
`evolve_geodesic()` 的末尾检测事件 ID，通过 `start_polarization()` 设置本征模 Stokes 初值并启动。

Mode 阶段发射/散射后若已经满足条件，仍由相同事件流程在初始点触发一次。
启动后关闭该事件并清除缓存符号；再次散射时复位 Mode，并以所选判据重新计算初始事件符号。
`--no-polarization` 对两种选择均禁用启动事件。Stokes 积分器、冻结条件和光学深度算法未改动。

## 性能比较方法

本次比较的是**当前同一个可执行文件的两个选项**，两个选项都使用测地线事件。
与此前“旧版本在 `advance_polarization` 中扫描 FD11 条件、新版本改为绝热事件”的对照不同。

编译使用 Homebrew GCC 16.2.0，`-std=c++23 -O3`，相同 GSL 参数，Darwin arm64。
每种选择先运行 100 光子预热，不计入正式结果。随后每组各运行三次，交替执行顺序，全部串行。
所有参数除判据名称外均相同，包含种子、发射初态、能量、偏振容差、冻结阈值和启动阈值。
完整进程墙钟时间包含初始化、模拟和输出；同时保存内部模拟循环计时。

当前驱动仍为随机表面位置、初始径向发射，散射后方向随机，本次没有修改发射模型。
因此性能结果适用于当前驱动，不自动代表所有非径向初始发射分布。
同一种子不意味着两种判据拥有相同散射历史，因为不同偏振会改变散射采样。
本测试比较整体工作量和耗时，没有单独剥离事件函数的耗时。

复现命令：

```sh
make fd11
python3 src/dev/py/benchmark_coupling_criteria.py
```

脚本支持 `--repeats` 和 `--timeout`。数据保存到 `output/fd11_coupling_criteria/`：
`metadata.json` 记录平台、编译信息、源码/二进制/磁场表 SHA256，`source.diff` 记录代码改动，
`runs.json` 保存各次命令、计时、计数、范数误差和输出哈希，`analysis.json` 保存统计结果。
各次光子数据和程序日志也保存在此目录。

默认配置的原始墙钟时间为：

- `fd11`：8.653237、8.732511、8.662756 秒。
- `adiabatic`：12.862115、12.762768、12.850736 秒。

若从当前默认 `adiabatic` 切换到 `fd11`，则耗时减少约 **32.6%**。

`adiabatic` 的接受步数较少，但拒绝步数、积分启动后的散射次数更多，且事件评估需要计算方向导数。
这些计数说明接受步数不能单独代表总成本；本次没有进行函数级性能剖析，不能把全部差距归因于其中一项。
两种初始化近似会改变光子后续的偏振与散射过程，输出的不同也不能直接解释为数值误差。

所有 **54 次**正式运行均正常结束，有限值、输出行数、逃逸/吸收计数和 Stokes 范数检查通过。
最大 $|Q^2+U^2+V^2-1|$ 为 **2.518e-13**。同一判据和配置的三次输出哈希一致；
禁用偏振时两种选项的输出也完全相同。

此前报告的约 20.3% 是两个旧提交的整体对照，其中 FD11 使用独立扫描流程。
本次 FD11 也使用 geodesic stepper 的事件，故本次的 48.3% 与此前百分比对应不同的对照对象。
