# 共振层防漏积分：实现与 benchmark

已将 `ode/main.cpp` 的默认传播改为 **几何 DOPRI5 + 共振面分段光深积分**（`event`）。在本次 180 条光线中，默认配置全部完成，最大光深相对误差为 **2.28×10⁻⁸**；更严格配置为 **3.48×10⁻⁹**。这些是实测误差，不是对任意初始条件的严格误差上界。

完整数据：[results.csv](results.csv)；自动汇总：[results.md](results.md)；旧代码复核：[original.csv](original.csv)。

## 为什么单纯调小容差不够

原程序把 `(r, psi, alpha, tau)` 一起交给 DOPRI5。若一次大步的全部 RK 节点都落在共振层外，所有节点的散射率都很小，嵌入误差估计也很小，积分器会接受这一步。误差控制并不知道节点之间还存在一整层散射物质。

另一个独立问题发生在 `D=x²+mu²−1=0`：两支共振速度合并，E 模散射率有 `D^(-1/2)` 奇点。横穿共振边界时它可积，但普通 RK 可能下溢，也可能在舍入噪声上反复积分而严重高估。只解决“找到层”并不等于正确积分奇点。

FT07 §3.4 的速度/动量分辨思路是重要参考。本项目仍按 `resonant.typ` 使用 Schwarzschild 传播和 `1/|mean(beta)|` 电流归一化，没有改回 FT07 印刷公式的逐根速度分母。论文：[本地 PDF](../article/FT07.pdf)、[作者预印本](https://arxiv.org/abs/astro-ph/0608281)；模型定义：[resonant.typ](../resonant.typ)。

## 实现

- [`ode/dopr5.hpp`](../ode/dopr5.hpp)：增加 `set_step_limiter(callback)`、导数/步数统计及非有限值检查；修正事件截断后 dense output 的区间一致性。普通事件仍依靠端点变号，不能单独防止跨过整个窄层。
- [`ode/resonance_limiter.hpp`](../ode/resonance_limiter.hpp)：用热分布在共振频率上的宽度和距共振区的距离限制步长。即使当前散射率接近零，也会主动减速。它是便宜的启发式方案，局部驻点和 E 模奇点仍是限制。
- [`ode/resonance_transport.hpp`](../ode/resonance_transport.hpp)：只用 DOPRI5 演化三个几何变量。每步最多 `0.1r`，在 dense trajectory 上查找 `D=0`、`x=1`、热速度地标、磁场插值节点和空间边界；加中间探测及驻点搜索以发现同号端点之间的双穿越。热地标取 `u=sqrt(a*(gamma−1))` 的 0、0.25、0.5、1、2、4、8，**仅作积分分段，未截断生产分布尾部**。
- 每段用开节点 Gauss–Kronrod 7/15 自适应积分。`l=l_left+width*sin²(pi*t/2)` 消除横截 `D=0` 的端点奇点；根附近用锚定零点的单侧四次插值稳定计算 D，并避免跨磁场插值节点拟合。精确保留变换后的端点距离，避免冷赤道的浮点消减。拟合尺度可通过 `discriminant_fit_step` 做收敛检查。
- 散射位置由非负累计光深积分反解 `tau=-log(U)`，不使用可能失去单调性的 RK 光深插值。`perform_scattering()` 与光深积分共用筛选后的共振根和权重。
- [`ode/transport_physics.hpp`](../ode/transport_physics.hpp) 提取可复用物理内核；利用 `|mu'|=sqrt(D)/x` 稳定共振权重，处理磁轴基底和径向散射退化。分布支持严格遵照 note；指数自由程采用开区间随机数。

## Benchmark 设计与参考值

固定当前磁场表 `bfield_t10.txt`、`B_pole=10^14 G`、`R_star=10 km`、`M_star=1.4 M_sun`、外边界 `10000 km`。固定光子能量、方向与偏振，沿整条**不执行散射的自由传播路径**计算总光深，隔离 Monte Carlo 抽样噪声。

共 180 条路径：154 条径向、26 条非径向，均包含 O/E 模。主网格覆盖 `beta0=-0.75,-0.2,-0.05,-0.005`，磁余纬余弦 `-0.8,-0.2,0,0.2,0.8`，能量 `0.1,1,10 keV`；另有 `|beta0|=0.001`、100 keV、正速度粒子、两磁轴、向内传播、径向转向、返星吸收，以及从实际共振层内部开始的案例。每行初始条件均保存在 CSV 中。

**径向参考独立于生产光深算法。** [`test/resonance_reference.hpp`](../test/resonance_reference.hpp) 直接交换 delta 函数积分次序，改用粒子速度变量：

\[
\tau=(p+1)\pi\frac{B_\phi}{B_\theta}
\int\frac{f(\beta)}{|\bar\beta|}\,
\frac{|e'|^2(1-\beta\mu)}{L[r(\beta)]Q[r(\beta)]}\,d\beta,
\quad L=\sqrt{1-r_s/r},\quad Q=2+p-\frac{r_s}{2(r-r_s)}.
\]

再换成 `u=sqrt(a*(gamma−1))`，使 `f/|mean(beta)| d beta` 化为 `2*(a+u²)/sqrt(2a+u²)*exp(-u²) du`，完全避开生产二次求根、散射率、RK、分布函数和 Bessel 归一化。参考积分截到 u=8，返回误差估计包含尾部上界、积分估计和舍入估计；传播端点也在速度空间显式分段。已检验反向对称性、区间可加性、容差收敛及平直时空赤道 E 模解析结果。

**非径向参考为收敛参考，不是完全独立实现。** 使用同一分段架构，但几何容差收紧至 `2e-13/2e-14`、光深容差至 `2e-10/2e-11`；最大步长从 `0.025r` 加密到 `0.0125r`，同时将 D 拟合尺度减半。两次结果最大绝对差 `3.65e-9`。径向/非径向结果分开汇总，避免把这一收敛检查等同于独立真值。

## 精度与效率

每条光线先预热一次，再独立运行 5 次，取耗时中位数；参考值计算、编译、读磁场表与 CSV 输出不计入单条传播计时。下表耗时是各案例耗时中位数的中位数。实验用 macOS 15.7.3 arm64，Homebrew GCC 16.2.0，`-O3 -std=c++23 -Wall -Wextra -Wpedantic`，无 fast-math。

| 方法 | 参数 | 异常终止 | 成功但误差>0.1% | 最大相对误差 | 中位耗时/光线 |
|---|---|---:|---:|---:|---:|
| 原理相同的无保护 RK | atol=rtol=1e-6 | 0 | 82 | 100% | 46 μs |
| 固定限步 | h≤0.01r，容差1e-6 | 0 | 32 | 100% | 557 μs |
| 更细固定限步 | h≤0.001r，容差1e-8 | 0 | 10 | 462% | 5404 μs |
| 分布感知限步 | resolution=0.1，h≤0.1r，容差1e-8 | 2 | 3 | 462% | 256.5 μs |
| **事件分段（默认）** | 几何rtol/atol=1e-9/1e-10，光深1e-7/1e-9 | **0** | **0** | **2.28e-8** | **959 μs** |
| 事件分段（严格） | 几何1e-11/1e-12，光深1e-9/1e-10 | 0 | 0 | 3.48e-9 | 1576 μs |

所有对照方法共享新的稳定物理内核，以便比较积分策略。RK 的光深初始残余为 −1，初始步长 0.01 km，沿全程累加后恢复总光深。事件方法初始几何步长 0.1 km，默认 h 上限0.1r。**局部容差数值不代表相同全局精度**，表中各配置是精度–耗时工作点，不能只凭容差数字判断公平性。

分布感知限步的典型耗时较低，但最困难的层内起步案例耗时约 1.88 秒，并把 `tau=873.451543570` 算成 `4905.212470752`。更细固定限步也有同类结果。事件默认最大单例耗时约 9.82 ms；径向/非径向耗时中位数分别约 0.910/5.15 ms。默认事件法中位耗时约为 h≤0.001r 方案的 1/5.6，同时避免了后者的漏算和奇点高估。

一个明确漏层例子：`beta0=-0.005, muz=0, energy=1 keV, E mode`，从星面径向出射。

| 方法 | 总光深 |
|---|---:|
| 独立参考 | 207.297242558911 |
| 无保护 RK | 0 |
| h≤0.001r | 0 |
| 默认事件分段 | 207.297245846695 |
| 严格事件分段 | 207.297242681538 |

这对应至少一次散射概率 `1-exp(-tau)` 从接近 1 被错误算成 0。默认事件法在全部测试中的最大概率绝对误差为 `3.43e-9`。但光深很大时概率饱和，所以还必须检查光深本身，不能只比较散射概率。

旧代码也独立复核过：从修改前提交 `2789b0e1cc075fd19241d75e5adff9771880c54e` 提取全部 ode 源码运行，`beta0=-0.005` 的南半球及赤道 O/E 四例都得到零光深。历史审查文档的 `beta0=-0.2,muz=-0.2` 例，在这个提交上不再整层漏算，不能把旧审查中的零结果冒充当前版本复现；其独立参考值仍成立。复核脚本为 [`replay_original.py`](replay_original.py)。

## 运行与验证

从项目根目录运行，需保留现有磁场表：

```sh
make                    # 编译默认事件传播主程序
./build/main
./build/main --photons 128 --mode E --beta0 -0.75
make check              # 积分器、独立参考、测地线、散射位置及集合回归
make benchmark          # 180例 × 6配置 × 5次计时，重写 results.csv/results.md
make benchmark-quick    # 12例快速检查
python3 benchmark/replay_original.py  # 复核修改前源码
```

`./build/main --method event|thermal|cap|rk` 可切换传播；后面三个保留作实验对照，不建议用于要求准确光深的正式计算。主程序 `cap` 为0.01r、耦合RK容差1e-8，和 benchmark 的两个固定工作点有所不同。`--seed`、`--energy`、`--mode`、`--beta0` 可设置初始模型。

本次验证通过：

- `make check`：解析窄层积分、正反向限步、事件顺序/dense output、异常输入；独立速度参考；径向/斜射/转向/吸收测地线不变量；按总光深10%/50%/90%指定的散射位置用独立径向参考核对；层内重启可加性；超冷赤道严格容差与拟合尺度减半；16光子、104次散射的集合回归。
- 主程序另跑两组128光子：`beta0=-0.75,E` 有126逃逸、2吸收、133次散射；`beta0=-0.2,O` 有125逃逸、3吸收、684次散射，均正常结束。它们是运行健壮性检查，不是谱的统计收敛证据。
- `make benchmark` 全部180例完成；默认/严格事件配置各180例均通过 `relative_error≤1e-6` 自动门槛。对照方法失败保留在数据中。

## 精度适用范围

误差针对**固定现有磁场表及模型**；没有把磁场插值误差、有限外边界误差或谱的 Monte Carlo 误差算进去。散射位置验证与总光深 benchmark 分开进行；上表时间是完整自由传播光深积分，不是整个多次散射模拟的平均耗时。

`estimated_quadrature_error` 只报告光深求积估计，不包含几何轨迹误差、根定位及 D 拟合偏差。应结合独立参考、步长和拟合尺度收敛检查使用。当前验证的最低 `|beta0|` 是0.001；中间探测/驻点搜索是针对当前平滑磁场的数值策略，不是任意磁场和任意掠射轨迹都不漏根的数学证明。若 D 与路径精确相切且 f(mu)>0，理想 delta 共振模型可能出现真实的对数发散；该情形需要额外物理展宽，不能用静默丢掉奇点解决。
